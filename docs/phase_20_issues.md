## Propmt 4
Иконка приложения съехала: сейчас в качестве адаптивной иконки используется
исходный квадратный файл, машина выходит за безопасную зону и смещена вверх.

Положи в assets/ файлы из архива (я их добавил):
- icon.png (1024x1024, непрозрачный)
- adaptive-icon-foreground.png (машина по центру, прозрачный фон)
- adaptive-icon-background.png (градиент + сетка, без машины)

В app.json приведи к виду:
"icon": "./assets/icon.png",
"android": {
  "package": <НЕ МЕНЯТЬ, оставить как есть>,
  "adaptiveIcon": {
    "foregroundImage": "./assets/adaptive-icon-foreground.png",
    "backgroundImage": "./assets/adaptive-icon-background.png"
  }
}

Убери старые ссылки на квадратный файл, если они где-то остались.
После сборки иконку надо смотреть на чистой установке —
лаунчер кеширует старую.

=== Экраны (3 штуки, горизонтальный свайп + точки-пагинация) ===
Все тексты через t(), все цвета через объект темы. Хардкод запрещён.
Работать должно в тёмной И светлой теме.

ЭКРАН 1 — Welcome
- Фон: чёрный, снизу вертикальный градиент в синий + бирюзовое свечение
  снизу (как на иконке приложения). expo-linear-gradient.
- Поверх фона тонкая сетка (tile-PNG 22x22, resizeMode repeat, opacity ~0.15).
- По центру лого 88x88, borderRadius 22, мягкое голубое свечение вокруг.
- Под ним «MyCarLedger», 21px, weight 500.
- Тонкая акцентная линия 34x2 под названием.
- Ниже слоган, две строки, по центру.
- Кнопка внизу: белая, текст цветом акцента, radius 15, padding 13.

ЭКРАН 2 — Данные машины
- Фон: чёрный + голубое свечение сверху (radial), сетка opacity ~0.07.
- Надзаголовок «ШАГ 1 ИЗ 2», цвет акцента, 10px, letterSpacing 1.2.
- Заголовок 19px + подпись.
- Поле 1: Название машины, иконка машины слева, плейсхолдер «Моя машина».
  Не обязательное — если пусто, сохраняем значение плейсхолдера.
- Поле 2: Текущий пробег, км. Иконка спидометра слева, keyboardType numeric.
  Обязательное. В фокусе — акцентная обводка + мягкое свечение.
- Кнопка «Далее»: градиент акцента, свечение снизу. Пока пробег пустой
  или не число — disabled (приглушённая, без градиента).

ЭКРАН 3 — Готово
- Фон: чёрный + зелёное свечение сверху, сетка opacity ~0.07.
- По центру круг 58x58: полупрозрачная зелёная заливка, обводка, галочка.
- Заголовок + подпись.
- Три карточки-подсказки, у каждой квадратная иконка-плашка 28x28 слева
  (полупрозрачный акцентный фон, radius 9).
- Кнопка «Поехали»: градиент акцента.

Пагинация внизу всех экранов: 3 точки, активная — вытянутая пилюля.

=== Сохранение ===
По кнопке «Поехали»:

- UPDATE APP_SETTINGS SET onboarding_completed = 1
- переход на дашборд с reset навигации (назад вернуться нельзя).
