## Что сделано (сессия 2026-10-08 … 2026-10-21)

### Основа и баги
- Новый билд на Samsung S25 (основной) и втором телефоне, чек-лист блоков A–I пройден.
- БАГ «данные переживают удаление приложения»: причина — Android Auto Backup. Исправлено `android.allowBackup: false` в `app.config.js`. Проверено: после удаления и установки — онбординг и пустая база.
- Stats: пустые вкладки за октябрь — не баг (нет расходов, расход считается только при ≥2 полных заправках). Добавлено: стрелки ‹ › по месяцам и «За всё время».

### Расход топлива
- Единая формула `calcConsumption()`: расход только у полного бака; литры неполных между двумя полными включаются. Пересчёт автоматически после add/update/delete и после импорта JSON.
- Одометр `recalcCurrentOdometer()` = max(base_odometer, пробеги заправок/расходов/ТО); при импорте пересчитывается.
- Средневзвешенный расход (сумма литров сегментов ÷ сумма км) на главной и в Stats «За всё время». Минимум/максимум/лучший/худший — по отдельным заправкам.
- Расход по месяцам: отрезок между полными баками делится по месяцам пропорционально пробегу (`getMonthlyFuelConsumption()`), май больше не пустой.
- Карточки Stats («Средний расход», «Пробег за месяц», «Минимум», «Максимум») считаются за выбранный месяц; для месяцев без закрывшейся полной заправки min/max берутся по отрезкам, пересекающим месяц; км округляются до целых.
- Тап по столбцу графика выбирает месяц (в «За всё время» отключён).
- Подписи периода: главная «за всё время», Stats «за период май–окт 2026» / «за <месяц>».
- Документы «как работает приложение»: `docs/how_it_works_tech.md`, `docs/how_it_works_simple.md`; ТЗ `docs/ТЗ_приложение_авто_финал.md` синхронизировано с кодом; `docs/CHANGELOG_work.md` ведётся по каждой правке.

### Напоминания (бывший «Сервис»)
- Регламенты можно создавать «задним числом»: по времени — «Когда сделано в последний раз» (дата), по пробегу — «Дата/Пробег при последней замене». Для «По времени» есть необязательное «Пробег при последнем выполнении» (в БД сентинел `-1` = не указан, в UI «—»).
- «Сделано» принимает пробег ниже текущего; одометр машины при этом не падает. `last_*` берутся из записи с самой поздней датой; откат при удалении записи работает.
- Сохранение уже просроченного регламента не шлёт лишний push (`primeNotifiedStatus`).
- Вкладка «Сервис» переименована в «Напоминания» / Reminders, иконка — колокольчик. Категория расходов «Сервис» не менялась.
