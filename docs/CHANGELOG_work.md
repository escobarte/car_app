# Журнал работы над проектом

Хронология выполненных задач. **Новые записи добавляются сверху.**
В каждой записи — только суть (что сделано), затронутые файлы и статус.

Статусы:
- `ждёт проверки на телефоне` — по умолчанию, сразу после выполнения;
- `проверено` — ставится только после устного подтверждения от пользователя.

---

## Пример формата записи

## ГГГГ-ММ-ДД
- что сделано (1-3 строки по сути)
- файлы: ...
- статус: ждёт проверки на телефоне
