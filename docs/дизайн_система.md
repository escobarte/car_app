# Дизайн-система «Учёт расходов на авто»

> Справочник цветов и стилей для обеих тем. Claude Code использует эти значения
> при создании экранов. Когда дойдём до кода — эти токены лягут в один файл
> темы (например `theme.ts`), а компоненты будут брать цвета оттуда, а не
> прописывать хардкодом.

---

## 1. Концепция

- Две темы: тёмная (основная, как в прототипе) и светлая.
- Главный акцент в обеих темах: голубой `#3db5f5`.
- Фирменный приём — голубой градиент на ключевых элементах (блок суммы,
  кнопка «+», кнопка Save, активные переключатели).
- Скруглённые углы, минимализм, активный элемент подсвечивается голубым.

---

## 2. Градиент акцента (одинаковый в обеих темах)

```
linear-gradient(135deg, #3db5f5 0%, #1a8fd6 100%)
```
Используется: блок Total Expenses, кнопка «+» в навигации, кнопки Save/Confirm,
включённые тумблеры, активные фильтры-таблетки.

| Элемент | Размер | Вес |
|---|---|---|
| Сумма (главная) | 34px | 500 |
| Заголовок экрана | 19px | 500 |
| Значение в карточке | 18px | 500 |

Используются два веса: 400 (обычный) и 500 (полужирный). Регистр — обычный
(не Caps), кроме мелких заголовков-секций в Settings.

---

## 7. Как переключаются темы

- Переключатель «Dark theme» живёт в Settings → Notifications/Appearance.
- По умолчанию приложение стартует в тёмной теме (как прототип).
- Технически: один объект темы выбирается по флагу, все компоненты читают
  цвета из него. Хардкод цветов в компонентах запрещён — только через тему.
- Реализуется на Этапе 9 (полировка), но цвета закладываются с самого начала,
  чтобы потом не переписывать каждый экран.

## 8. Адаптивность

### Целевой диапазон

От **360 dp** (Samsung Galaxy S10, бюджетные Android-устройства) до планшетов.
Вёрстка должна корректно отображаться на любом устройстве в этом диапазоне
без горизонтального скролла и без обрезанного контента.

---

### Запрещено и разрешено

| Элемент | Запрещено | Правильно |
|---|---|---|
| Ширина кнопок и таблеток | `width: 120` (фиксированный px) | `flex: 1` или `flexBasis: '48%'` |
| Ширина карточек | `width: 340` | без `width`, контейнер растягивается сам |
| Ширина строк форм | `width: 300` | `alignSelf: 'stretch'` или без `width` |
| Иконки и отступы | — | фиксированные px **допустимы**: они не зависят от текста |

> Правило: если размер зависит от содержимого или текста — только `flex` или
> проценты. Иконки и `gap`/`padding` можно задавать фиксированными px.

---

### Высота блоков

Вместо `height` использовать `minHeight` — иначе при крупном системном шрифте
Android текст выйдет за рамки контейнера.

```ts
// ✗ ломается при крупном шрифте
height: 48

// ✓ растягивается под содержимое
minHeight: 48,
paddingVertical: 12,
```

---

### Ряды кнопок и переключателей

Контейнер — `flexDirection: 'row'`. Каждый элемент — `flex: 1`. Отступ
между элементами — `gap` (не `marginLeft`/`marginRight` у каждого вручную).

```ts
row: {
  flexDirection: 'row',
  gap: 8,
},
item: {
  flex: 1,
  minHeight: 44,
  paddingVertical: 10,
},
```

---

### Текст в кнопках и таблетках

Длинные подписи (особенно на EN) не должны обрезаться или переноситься.

```tsx
<Text
  numberOfLines={1}
  adjustsFontSizeToFit
  minimumFontScale={0.85}
>
  {label}
</Text>
```

- `numberOfLines={1}` — запрещает перенос строки.
- `adjustsFontSizeToFit` — уменьшает шрифт, если текст не помещается.
- `minimumFontScale={0.85}` — не меньше 85 % от оригинального размера
  (примерно −2 pt для 14 px-текста), ниже — лучше обрезать через `ellipsizeMode`.

---

### Сетки метрик 2 × 2

Не задавать ячейкам фиксированную ширину в px. Контейнер — `flexWrap: 'wrap'`,
каждая ячейка — ~48 % ширины через `flexBasis`.

```ts
metricsGrid: {
  flexDirection: 'row',
  flexWrap:      'wrap',
  gap:           10,
},
metricCell: {
  flexBasis:    '47%',   // ≈ половина ширины за вычетом gap
  flex:         1,       // подравнивает последнюю строку
  minHeight:    72,
  padding:      12,
},
```

---

### Длинные значения (суммы, пробег)

Суммы и пробег могут быть большими. Не обрезать их через `numberOfLines={1}`
без `adjustsFontSizeToFit` — иначе пользователь видит «12 3…» вместо «12 345 ₽».

```tsx
<Text
  style={s.metricValue}
  adjustsFontSizeToFit
  minimumFontScale={0.7}
  numberOfLines={1}
>
  {value}
</Text>
```

---

### Проверка нового экрана

Каждый новый экран перед сдачей проверить:

1. **EN-локаль** — английские строки длиннее русских и первыми ломают вёрстку.
   Переключиться в Settings → Язык → EN и пройтись по всем состояниям экрана.
2. **Мелкий экран** — 360 dp. Если нет устройства, уменьшить эмулятор.
3. **Крупный системный шрифт** — в настройках Android поднять размер шрифта
   до «Большой» и убедиться, что кнопки и карточки не обрезают текст.
