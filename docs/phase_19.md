**Промпт 4 — подтверждение при создании регламента + время уведомлений**
```
Две связанные правки по регламентам.

1) Время push-уведомлений
Сейчас регламенты типа time считаются по дням, но время срабатывания
не задано явно. Зафиксируй: все уведомления по регламентам приходят
в 9:00 утра по часовому поясу телефона.
Планирование через календарный триггер с hour: 9, minute: 0.
Если момент срабатывания уже прошёл сегодня — планируем на следующий
подходящий день, а не мгновенно.
Применить и к типу mileage (когда статус переходит в «пора»),
и к типу time.

2) Pop-up после создания регламента
После сохранения нового регламента (и после редактирования существующего)
показывать модалку-подтверждение с понятным человеку текстом:
- название регламента;
- как считается: «каждые 8 000 км» или «каждые 365 дней»;
- когда предупредит: «за 500 км до срока» / «за 25 дней до срока»;
- конкретная дата и время срабатывания для типа time —
  например «Уведомление придёт 15 августа 2026 в 9:00»;
- для типа mileage — при каком пробеге сработает:
  «Уведомление придёт при пробеге 213 906 км».
Кнопка «Понятно». Стиль модалки — тот же компонент, что используется
для деталей на дашборде.

Если уведомления выключены в Settings — в модалке дополнительной строкой
предупредить, что push не придёт, пока они отключены.

Цвета через объект темы, текст через t() (RU+EN), хардкод запрещён.
Даты форматировать по текущему языку интерфейса.
Git не трогай. Запиши в docs/CHANGELOG_work.md.
Обнови docs/ТЗ_приложение_авто_финал.md §6.3 — зафиксируй время 9:00.
```
