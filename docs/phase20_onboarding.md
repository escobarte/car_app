Читай ТЗ (разделы 4.6, 5.1, 5.7) и дизайн-систему в Files проекта.

Визуальный ориентир: assets/examples/mockup_onboarding.jpg — три экрана
онбординга слева направо (Welcome / Данные машины / Готово).
Ориентируйся на него по композиции: расположение блоков, отступы, размеры
лого и кнопок, характер фонового свечения и сетки, оформление полей и
карточек-подсказок, вид пагинации.

Важно: это мокап, а не эталон пикселей.
- Цвета бери из объекта темы, не пипеткой с картинки.
- Тексты бери из словарей i18n ниже, а не с картинки.
- Лого на мокапе нарисовано схематично — в приложении ставь реальный
  assets/icon-rounded.png.
- Мокап только в тёмной теме; светлую собери по дизайн-системе,
  сохранив ту же композицию.

Git-операции не делай — коммичу сам.

=== 1. Хранение флага ===
- В таблицу APP_SETTINGS добавь поле onboarding_completed BOOLEAN NOT NULL DEFAULT 0.
- Сделай это МИГРАЦИЕЙ, а не пересозданием таблицы: существующая база
  на телефоне не должна упасть и не должна потерять данные.
- Для уже существующих баз (там есть машина и записи) выставь
  onboarding_completed = 1, чтобы онбординг не показался тем, кто уже пользуется.
- Импорт бэкапа (экспорт/импорт JSON) тоже должен ставить флаг в 1.

=== 2. Роутинг ===
- При старте приложения читаем флаг ДО отрисовки навигации.
- onboarding_completed = 0 → показываем стек онбординга вместо табов.
- = 1 → обычная навигация (4 таба + «+»).
- Пока флаг читается — держим splash / пустой чёрный экран, без мигания.
- В Settings добавь пункт «Показать онбординг заново» (сбрасывает флаг) —
  нужно для тестов на телефоне.

=== 3. Экраны (3 штуки, горизонтальный свайп + точки-пагинация) ===
Все тексты через t(), все цвета через объект темы. Хардкод запрещён.
Работать должно в тёмной И светлой теме.

ЭКРАН 1 — Welcome
- Фон: чёрный, снизу вертикальный градиент в синий + бирюзовое свечение снизу
  (как на иконке приложения). expo-linear-gradient.
- Поверх фона — тонкая сетка (tile-PNG 22×22, resizeMode repeat, opacity ~0.15).
- По центру: лого приложения (assets/icon-rounded.png), 88x88, borderRadius 22.
- Под ним название «MyCarLedger», 21px, weight 500.
- Тонкая разделительная линия-акцент 34x2 под названием.
- Ниже слоган (2 строки, по центру).
- Кнопка внизу: белая, текст цветом акцента, radius 15, padding 13.

ЭКРАН 2 — Данные машины
- Фон: чёрный + голубое свечение сверху (radial), сетка opacity ~0.07.
- Надзаголовок «ШАГ 1 ИЗ 2», цвет акцента, 10px, letterSpacing 1.2.
- Заголовок «Твоя машина» 19px + подпись «Это можно изменить позже в настройках».
- Поле 1: Название машины. Иконка ti-car слева. Плейсхолдер «Моя машина».
  Не обязательное — если пусто, сохраняем плейсхолдер как значение.
- Поле 2: Текущий пробег, км. Иконка спидометра слева. keyboardType numeric.
  Обязательное. В фокусе — акцентная обводка + мягкое свечение.
- Кнопка «Далее»: градиент акцента. Пока пробег пустой или не число — disabled
  (приглушённая, без градиента).

ЭКРАН 3 — Готово
- Фон: чёрный + зелёное свечение сверху, сетка opacity ~0.07.
- По центру круг 58x58 с полупрозрачной зелёной заливкой, обводкой и галочкой.
- Заголовок «Всё готово» + подпись «Можно начинать вести учёт».
- Три карточки-подсказки, у каждой квадратная иконка-плашка слева:
  1) «+» — «Кнопка «+» — заправка, расход, сервис»
  2) ключ — «Регламенты созданы — отметь последнее ТО»
  3) загрузка — «Есть бэкап? Импортируй в настройках»
- Кнопка «Поехали»: градиент акцента.

Пагинация внизу всех экранов: 3 точки, активная — вытянутая пилюля.

=== 4. Сохранение ===
По кнопке «Поехали»:
- UPDATE CAR SET name = ?, current_odometer = ?
- UPDATE APP_SETTINGS SET onboarding_completed = 1
- переход на дашборд с reset навигации (назад в онбординг вернуться нельзя).
