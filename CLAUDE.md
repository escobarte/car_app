# Журнал работы (CHANGELOG)

После каждой выполненной задачи дописывать запись в НАЧАЛО файла
`docs/CHANGELOG_work.md` (новые записи сверху) по формату:

```
## ГГГГ-ММ-ДД
- что сделано (1-3 строки по сути)
- файлы: ...
- статус: ждёт проверки на телефоне
```

Правила:
- Записывать только суть, без мелочей.
- Статус по умолчанию — «ждёт проверки на телефоне».
- Менять на «проверено» ТОЛЬКО когда пользователь подтвердит это словами.
